# 프로그래머스 42627 - 디스크 컨트롤러

- 난이도: Level 3
- 분류: 우선순위 큐, 스케줄링
- [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/42627)

## 문제 요약

각 작업의 요청 시각과 소요 시간이 주어진다. 디스크가 비어 있을 때 대기 중인 작업을 정해진 우선순위로 실행하여, 모든 작업의 요청부터 종료까지 걸린 시간의 평균을 구한다.

## 풀이 접근

작업을 요청 시각 순서로 먼저 정렬한다. 현재 시각까지 요청된 작업을 우선순위 큐에 넣고, 큐에서 다음 기준으로 실행할 작업을 선택한다.

1. 소요 시간이 짧은 작업
2. 요청 시각이 빠른 작업
3. 작업 번호가 작은 작업

작업을 하나 끝낼 때마다 `종료 시각 - 요청 시각`을 누적한다. 대기 중인 작업이 없다면 시간을 한 칸씩 증가시키지 않고 다음 작업의 요청 시각으로 바로 이동한다.

## 핵심 포인트

- 현재 시각까지 들어온 작업이 여러 개일 수 있으므로 `if`가 아니라 `while`로 큐에 넣는다.
- 우선순위 큐는 이미 요청되어 대기 중인 작업만 포함한다.
- 합계가 커질 수 있으므로 총 반환 시간은 `long`으로 계산한다.
- 마지막 평균은 정수 나눗셈으로 소수점 이하를 버린다.

## 복잡도

- 시간: `O(N log N)`
- 공간: `O(N)`

각 작업은 정렬되고 우선순위 큐에 한 번씩 삽입·삭제된다.
