# 프로그래머스 42579 - 베스트앨범

- 난이도: Level 3
- 분류: 해시, 정렬
- [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/42579)

## 문제 요약

장르별로 가장 많이 재생된 노래를 모아 베스트 앨범을 만든다. 먼저 총 재생 횟수가 많은 장르가 앞에 오고, 각 장르에서는 재생 횟수가 많은 노래를 최대 두 곡까지 선택한다. 재생 횟수가 같다면 고유 번호가 작은 노래를 먼저 선택한다.

## 풀이 접근

한 번의 순회로 다음 두 정보를 함께 만든다.

- `genreTotal`: 장르별 총 재생 횟수
- `genreSongs`: 장르별 노래 목록

그다음 장르를 총 재생 횟수의 내림차순으로 정렬한다. 각 장르의 노래는 재생 횟수 내림차순, 고유 번호 오름차순으로 정렬하고 앞에서 최대 두 곡의 고유 번호를 정답에 추가한다.

## 핵심 포인트

- 장르의 우선순위와 장르 내부 노래의 우선순위는 서로 다른 기준으로 정렬해야 한다.
- 장르에 노래가 하나뿐이면 한 곡만 선택한다.
- 재생 횟수가 같은 노래의 순서를 정하기 위해 고유 번호를 함께 저장한다.

## 복잡도

- 시간: `O(N log N)`
- 공간: `O(N)`

`N`은 전체 노래 수이다. 장르 및 각 장르의 노래를 정렬하는 비용이 전체 시간 복잡도를 결정한다.
