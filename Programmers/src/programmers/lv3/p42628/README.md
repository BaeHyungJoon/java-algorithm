# 프로그래머스 42628 - 이중우선순위큐

- 난이도: Level 3
- 분류: 트리, 우선순위 큐
- [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/42628)

## 문제 요약

숫자 삽입, 최댓값 삭제, 최솟값 삭제 연산을 처리한다. 모든 연산이 끝난 뒤 큐가 비어 있으면 `[0, 0]`, 그렇지 않으면 `[최댓값, 최솟값]`을 반환한다.

## 풀이 접근

정렬된 키를 유지하는 `TreeMap<Integer, Integer>`을 사용한다.

- 키: 저장된 숫자
- 값: 같은 숫자가 저장된 개수

삽입할 때 숫자의 개수를 증가시킨다. 최댓값은 `lastKey()`, 최솟값은 `firstKey()`로 찾는다. 삭제 대상이 하나만 남았다면 키를 제거하고, 여러 개라면 개수만 감소시킨다.

## 핵심 포인트

- 같은 값이 여러 번 들어올 수 있으므로 집합이 아니라 개수까지 관리해야 한다.
- 비어 있는 큐에 대한 삭제 명령은 무시한다.
- 하나의 정렬 자료구조에서 최솟값과 최댓값을 모두 관리하므로 두 힙의 동기화가 필요 없다.

## 복잡도

- 시간: 연산 `M`개에 대해 `O(M log K)`
- 공간: `O(K)`

`K`는 큐에 존재하는 서로 다른 숫자의 최대 개수이다.
