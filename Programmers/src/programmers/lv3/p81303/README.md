# 프로그래머스 81303 - 표 편집

- 난이도: Level 3
- 분류: 연결 리스트, 스택
- [문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/81303)

## 문제 요약

표의 한 행을 선택한 상태에서 위·아래 이동, 현재 행 삭제, 최근 삭제 행 복구 명령을 처리한다. 모든 명령이 끝난 뒤 각 행의 존재 여부를 `O`와 `X`로 표현한다.

## 풀이 접근

실제 연결 리스트 객체 대신 두 배열로 각 행의 연결 관계를 표현한다.

- `prev[i]`: `i`번 행 바로 위의 살아 있는 행
- `next[i]`: `i`번 행 바로 아래의 살아 있는 행

행을 삭제할 때 위아래 행을 직접 연결하고, 삭제된 행 번호와 당시 이웃을 스택에 저장한다. 복구 명령이 들어오면 스택에서 가장 최근 정보를 꺼내 이전 연결 관계를 되살린다.

## 핵심 포인트

- 삭제와 복구는 배열의 링크만 변경하므로 각각 `O(1)`이다.
- 마지막 행을 삭제하면 커서를 위쪽 행으로, 그 외에는 아래쪽 행으로 옮긴다.
- 복구는 가장 최근 삭제부터 처리되므로 스택이 적합하다.
- 삭제된 행을 실제 배열에서 제거하지 않고 결과 배열의 문자만 `X`로 변경한다.

## 복잡도

- 시간: `O(N + C + S)`
- 공간: `O(N)`

`N`은 행 수, `C`는 명령 수, `S`는 모든 위·아래 이동 거리의 합이다. 삭제와 복구는 상수 시간에 처리된다.
