# SWEA 1976 - 시각 덧셈

- 난이도: D2
- 분류: 구현, 수학
- 구현 상태: 미완성

## 문제 요약

시와 분으로 표현된 두 시각을 더한다. 분이 60 이상이면 시간으로 올림하고, 시간은 12시간 표기에 맞게 변환하여 출력한다.

## 구현 방향

현재 `Solution.java`에는 테스트 케이스 반복과 입출력 골격만 있고 실제 계산 로직은 아직 작성되지 않았다. 다음 순서로 구현할 수 있다.

1. 두 시각의 시와 분을 읽는다.
2. 분을 더하고 `minute / 60`을 시간에 더한다.
3. 분은 `minute % 60`으로 정규화한다.
4. 시간이 12를 넘으면 12시간 표기에 맞게 조정한다.
5. `#테스트케이스 시 분` 형식으로 결과를 저장한다.

두 시각을 각각 분 단위로 바꿔 더한 뒤 다시 시와 분으로 나누는 방법도 가능하다.

## 주의할 점

- 정확히 12시가 되는 경우를 `0시`로 출력하지 않도록 주의한다.
- `StringTokenizer`로 한 줄의 네 정수를 읽을 수 있다.
- SWEA 출력 형식에 맞게 테스트 케이스 번호를 붙여야 한다.

## 예상 복잡도

- 시간: 테스트 케이스 하나당 `O(1)`
- 공간: `O(1)`
