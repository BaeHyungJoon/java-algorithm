# SWEA 1954 - 달팽이 숫자

- 난이도: D2
- 분류: 구현, 2차원 배열

## 문제 요약

`N x N` 배열에 `1`부터 `N²`까지의 숫자를 시계 방향 달팽이 모양으로 채워 출력한다.

## 풀이 접근

오른쪽, 아래, 왼쪽, 위 순서의 방향 배열을 만들고 `(0, 0)`에서 시작한다. 현재 칸에 숫자를 쓴 뒤 다음 위치를 계산한다. 다음 위치가 배열 밖이거나 이미 채워진 칸이면 방향을 시계 방향으로 한 번 전환한 후 이동한다.

```text
오른쪽 → 아래 → 왼쪽 → 위 → 오른쪽 ...
```

배열의 초기값이 `0`이므로 `snail[nextRow][nextCol] != 0`을 통해 방문 여부를 별도 배열 없이 확인할 수 있다.

## 핵심 포인트

- 마지막 숫자를 쓴 뒤에는 다음 위치를 계산하지 않고 반복을 종료한다.
- 범위 검사 후에만 배열 값에 접근해야 인덱스 예외가 발생하지 않는다.
- 방향 전환은 `(direction + 1) % 4`로 순환시킨다.
- 여러 테스트 케이스의 출력을 `StringBuilder`에 모아 한 번에 출력한다.

## 복잡도

- 시간: 테스트 케이스 하나당 `O(N²)`
- 공간: `O(N²)`
