# SWEA 7733 - 치즈 도둑

- 난이도: D4
- 분류: 그래프 탐색, BFS/DFS, 연결 요소
- 구현 상태: 미완성

## 문제 요약

날짜가 지날 때마다 해당 날짜 이하의 맛있는 정도를 가진 치즈 칸이 사라진다. 각 날짜에 남아 있는 치즈 덩어리의 개수를 구하고, 그중 최댓값을 출력한다. 상하좌우로 연결된 치즈를 하나의 덩어리로 본다.

## 구현 방향

현재 `Solution.java`에는 테스트 케이스 반복과 입출력 골격만 있고 탐색 로직은 아직 작성되지 않았다. 다음 순서로 구현할 수 있다.

1. `N x N` 치즈의 맛있는 정도를 입력받고 최댓값을 구한다.
2. 아무 치즈도 먹지 않은 0일부터 최대 맛있는 정도까지 날짜를 순회한다.
3. 현재 날짜보다 큰 값을 가진 칸만 남아 있다고 판단한다.
4. 방문하지 않은 생존 칸에서 BFS 또는 DFS를 시작하고 덩어리 수를 증가시킨다.
5. 날짜별 덩어리 수의 최댓값을 갱신한다.

## 핵심 포인트

- 0일에는 모든 치즈가 남아 있으므로 덩어리 수가 최소 1일 수 있다.
- 연결 여부는 대각선을 제외한 상하좌우만 확인한다.
- 날짜가 바뀔 때마다 방문 배열을 새로 초기화해야 한다.
- 재귀 DFS는 입력 크기에 따라 호출 깊이가 커질 수 있으므로 큐를 사용하는 BFS도 안전한 선택이다.

## 예상 복잡도

- 시간: `O(H x N²)`
- 공간: `O(N²)`

`H`는 치즈의 최대 맛있는 정도이다. 각 날짜마다 전체 격자를 한 번씩 탐색한다.
